Q&A:

1.What is JavaScript?
JavaScript is a high-level, interpreted programming language mainly used for creating interactive and dynamic content on websites. It runs in the browser and allows developers to add functionality like animations, form validation, and interactive elements.

2.What is a variable?
A variable is a named storage location in memory that holds data. It allows you to store, update, and retrieve values during program execution.

4.What is initialization?
Initialization means assigning an initial value to a variable at the time of declaration.
Example:let username="Naveen"


5.What is an assignment operator?
The assignment operator (=) is used to assign values to variables.
Example: let age="23"

6.What are var, let and const?
var → Old way of declaring variables (function-scoped).

let → Modern way, block-scoped, allows reassignment.

const → Block-scoped, but cannot be reassigned after initialization.


7. What is the difference between var, let and const?

let is used to declare variables whose value can be reassigned.
Example:
let username = "React";
username = "JavaScript";

var is the older/traditional way of declaring variables.
Example:
var username = "React";
var city = "Chennai";

const is used when the variable should not be reassigned.
Example:
const course = "React";
The following is not allowed:
const course = "React";
course = "JavaScript";

8.What is ES6?
ES6 (ECMAScript 2015) is a major update to JavaScript that introduced new features like:

let and const

Arrow functions (()=>)

Template literals (`Hello ${name}`)

Classes

Modules (import/export)

Promises

9.What is a JavaScript Engine?
A JavaScript Engine is a program that executes JavaScript code. It parses, compiles, and runs the code inside browsers or environments like Node.js.

10.What is V8?
V8 is Google’s open-source JavaScript engine, used in Chrome and Node.js. It compiles JavaScript into machine code for faster execution, making it one of the fastest engines available.
